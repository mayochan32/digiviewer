# v0.6.2 和名辞書の拡充と検証（公開前）

2026-10-12。修正ブランチ: `codex/expand-japanese-species-dictionary`。

## 結果

- 同梱辞書を **12,580 → 40,178学名**に拡張。追加 **27,598学名**、約3.19倍。既存の出典付き旧学名対応2件はこの件数に含めない。
- 追加分の出典: 国土技術政策総合研究所25,809学名、Wikidata1,789学名。両者が同じ和名を返す場合は国内リストの出典を優先し、重複は数えない。
- `Coccinella ainu` は **アイヌテントウ**（国総研・種コード76624）と表示。`Coccinella septempunctata` の **ナナホシテントウ**は従来どおり。
- 新規学名で和名が食い違う53件は追加せず、既存の名前と食い違う161件は従来の表示を維持。詳細は[監査データ](japanese-names-expansion-audit.json)。

## 実際のモデル候補での和名表示率

BioCLIP 2の分類候補に含まれ、2026-09-22取得のGBIF日本記録が1件以上ある**重複しない学名**を分母にした。学名の組み立ては現行workerと同じ。以前と今回で同じ分母・同じ別名対応を使った。

| 分類群 | 対象学名 | v0.6.1 | 今回 |
|---|---:|---:|---:|
| 昆虫 | 11,404 | 746（6.5%） | 5,595（49.1%） |
| 鳥 | 987 | 696（70.5%） | 947（95.9%） |
| 全分類群 | 54,054 | 7,293（13.5%） | 16,617（30.7%） |

この数値は**和名を表示できる割合**であり、写真を正しく判定できる割合ではない。日本の生物全体の網羅率でもなく、国内記録には外来種・飼育・誤記録などが含まれ得る。各学名を同じ重みで数えており、実際によく撮影する種の頻度による評価ではない。候補順位・相対スコア・切り出し処理は変更していない。

入力のモデルラベルSHA-256: `4648928b006f85d83d28e5a27074ca9363465d82e778d708b369c5eaf54b8ef5`。
国内記録のSHA-256: `add1f8502bf15819e1f72dfa4051d532190b233b3e51e435559ae394d519f051`。

## 国内リストとの照合

取り込み条件（二名法の学名、カタカナの種和名）を満たす国総研リスト内の学名に対する表示件数:

- 昆虫: 499 / 20,842 → 20,834 / 20,842。
- 鳥: 537 / 685 → 677 / 685。

取り込みに使った資料自身との照合なので、前項のモデル候補での数値とは分ける。元リストの亜種・属・不明種・学名しかない和名欄はこの分母に入れない。和名が見つからない候補は学名のままとし、似た学名から補完しない。

## 取得範囲と利用条件

- **Wikidata（CC0）**: 日本語Wikipedia記事の条件を外し、日本の記録があるモデル候補54,054学名について150件ずつ照会した。全361照会を完了し、種階級・学名・日本語ラベルの応答を取得。カタカナの和名等の条件を満たす9,607学名を照合した。全世界の日本語ラベルを網羅したものではない。全体検索は公開サーバーの制限で時間切れになるため採用せず、不完全な応答も使用していない。[利用条件](https://www.wikidata.org/wiki/Wikidata:Licensing)
- **国土技術政策総合研究所（PDL1.0）**: 「河川水辺の国勢調査のための生物リスト（令和7年度）」全生物種ファイルを2026-10-12に取得。二名法とカタカナの和名がある29,853学名を照合。プランクトン専用行は別の令和8年度版があるため対象外。資料をDigiViewerが加工した旨と出典をアプリと同梱データに表示する。[生物リスト掲載ページ](https://www.nilim.go.jp/lab/fbg/ksnkankyo/mizukokuweb/system/seibutsuListfile.htm)、[利用条件](https://www.nilim.go.jp/aboutlink.htm)

出典ID・種コード／Wikidata ID・取得日・入力資料のハッシュを同梱する。[再生成方法](../src/data/README.md)も記録した。無料の公開データを開発時に取り込み、利用者側の追加通信・アカウント・費用・実行環境変更は発生しない。和名辞書はアプリ更新だけで反映され、追加モデルの再導入は不要。
