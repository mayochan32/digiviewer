# v0.6.2 和名辞書の拡充と検証（公開前）

2026-10-13更新（資料取得: 2026-10-12）。修正ブランチ: `codex/expand-japanese-species-dictionary`。

## 結果

- 同梱辞書を **12,580 → 42,600学名**に拡張。合計で **30,020学名分を追加**。既存の出典付き旧学名対応2件はこの件数に含めない。
- 前段階までの追加分の出典: 国土技術政策総合研究所25,809学名、Wikidata1,789学名。両者が同じ和名を返す場合は国内リストの出典を優先し、重複は数えない。
- `Coccinella ainu` は **アイヌテントウ**（国総研・種コード76624）と表示。`Coccinella septempunctata` の **ナナホシテントウ**は従来どおり。
- 前段階で新規学名の和名が食い違う53件は追加せず、既存の名前と食い違う161件は従来の表示を維持。詳細は[監査データ](japanese-names-expansion-audit.json)。

## 昆虫の追加拡充

- 前段階の40,178学名に **1,749学名分**を追加し、計41,927学名。内訳はCatalogue of Lifeの種階級の和名1,577学名、確認済みの異名を使って既存辞書につなげた172学名（受容種名48、同タイプ異名124）。学名単位で数えるので、同じ生物を指す異名も含む。
- **トラマルハナバチ**（Bombus diversus）、**キイロテントウ**（Illeis koebelei）、**ベニヒカゲ**（Erebia niphonica）、**ミヤマアカネ**（Sympetrum pedemontanum）などを追加。
- **ヤマトシジミ**（Zizeeria maha → Pseudozizeeria maha）、**ゴマシジミ**（Maculinea teleius / Phengaris teleius）、**ジャコウアゲハ**（Byasa alcinous / Atrophaneura alcinous）は出典の分類ID・異名関係を確認した。
- 前段階で未収録だった昆虫5,809学名を完全一致検索し、対応が明確な4,414件の受容種の詳細を確認。メタデータを含む10,224応答をキャッシュ・ハッシュ記録した。
- 新たな和名の競合207学名、分類上の問題350学名、同名の候補が複数ある461学名などは追加しない。出典に和名がない項目も2,428学名残る。全不採用理由と採用根拠は[昆虫追加の監査記録](japanese-insect-names-audit.json)。
- 元の辞書40,178学名と既存の旧学名対応は維持。亜種から和名を切り詰めたり、学名の文字の類似で補完したりしない。種階級が明示された亜属表記は出典の同一IDを確認して扱う。

## 実際のモデル候補での和名表示率

BioCLIP 2の分類候補に含まれ、2026-09-22取得のGBIF日本記録が1件以上ある**重複しない学名**を分母にした。学名の組み立ては現行workerと同じ。比較には同じ分母を使い、今回追加した異名対応も表示できる学名に含めた。

| 分類群 | 対象学名 | v0.6.1 | 国内リスト等追加後 | COL追加後 | 今回 |
|---|---:|---:|---:|---:|---:|
| 昆虫 | 11,404 | 746（6.5%） | 5,595（49.1%） | 7,344（64.4%） | **8,017（70.3%）** |
| 鳥 | 987 | 696（70.5%） | 947（95.9%） | 947（95.9%） | 947（95.9%） |
| 全分類群 | 54,054 | 7,293（13.5%） | 16,617（30.7%） | 18,366（34.0%） | 19,039（35.2%） |

この数値は**和名を表示できる割合**であり、写真を正しく判定できる割合ではない。日本の生物全体の網羅率でもなく、国内記録には外来種・飼育・誤記録などが含まれ得る。各学名を同じ重みで数えており、実際によく撮影する種の頻度による評価ではない。候補順位・相対スコア・切り出し処理は変更していない。

入力のモデルラベルSHA-256: `4648928b006f85d83d28e5a27074ca9363465d82e778d708b369c5eaf54b8ef5`。
国内記録のSHA-256: `add1f8502bf15819e1f72dfa4051d532190b233b3e51e435559ae394d519f051`。

## 今回の追加673学名

未収録の昆虫4,060学名に対し、次の順序で照合した。追加後も3,387学名は未収録。

| 方法 | 追加学名 | 例 |
|---|---:|---|
| COLの亜属表記・同一受容種IDの重複を照合 | 135 | クロオサムシ、ヒラタクワガタ |
| iNaturalistの種階級・同一学名・同一科の和名 | 513 | ゴマダラカミキリ、オオヒカゲ |
| 環境省の対象種一覧の種階級の行 | 5 | ゴマダラチョウ、オオクワガタ |
| S-Netの2機関以上の標本を照合 | 19 | アブラナマメヒメハナバチ、チャバネアオカメムシ |
| 出典の共通識別子を確認した表記の対応 | 1 | ウラジロミドリシジミ |

- COLでは同じ科にある候補をすべて確認し、受容種IDが同じ場合だけ統合。別種、問題フラグ付きの候補、不完全な応答は除外。GBIFの照合結果だけでは採用せず、固定版COLのID・学名・分類を再確認した。
- iNaturalistは2026-10-01版の学名と和名を照合。亜種は切り詰めず、複数の和名がある場合や他出典との競合は除外。写真や観察地点は使っていない。
- 環境省の5資料から二名法が明記された817行を抽出し、科・和名の一致を確認。採用5件のPDF上の行も目視照合した。1997年の資料であり、現在の分類を網羅するものではない。
- S-Netは残った学名のうち国内記録が多く、先行資料に和名がなかった60学名を対象に20,045標本行を取得。完全に取得できた57検索と該当なし3検索を記録。学名と和名が一意で、別々の2機関の標本についてGBIF側の同じ機関・コレクション・標本番号（あればUUIDも）と一致し、種階級・昆虫・同じ科・和名・再利用条件も一致するものだけを採用した。21学名が条件を満たし、環境省分との重複2件を除く19学名を追加。S-Net全体の網羅的収集ではない。
- `Favonius saphirina` はCOLにあるWikidata識別子が既存辞書の `Favonius saphirinus` と一致することを確認し、既存の「ウラジロミドリシジミ」を使用。資料中の「ウラジロミドリジシミ」は自動採用せず、この1件の判断理由を記録した。
- 昆虫モデルと同名の植物が見つかった `Viola minor`、複数の和名があった `Ladoga camilla`・`Coeliccia ryukyuensis` などは未収録のまま。

採用根拠・不採用理由・出典ID・応答のハッシュは[今回の監査記録](japanese-insect-names-extended-audit.json)に保存。既存41,927学名の表示は維持し、判定順位やスコアは変えていない。

## 国内リストとの照合

取り込み条件（二名法の学名、カタカナの種和名）を満たす国総研リスト内の学名に対する表示件数:

- 昆虫: 499 / 20,842 → 20,834 / 20,842。
- 鳥: 537 / 685 → 677 / 685。

取り込みに使った資料自身との照合なので、前項のモデル候補での数値とは分ける。元リストの亜種・属・不明種・学名しかない和名欄はこの分母に入れない。和名が見つからない候補は学名のままとし、似た学名から補完しない。

## 検証範囲

- 辞書・旧学名・未収録・出典・全既存名の保持・アプリの独立性・版番号の一致: Nodeの11テスト。
- データ作成時の属／亜種／不明種除外、競合の処理、Excel・PDF行の読み取り、同一分類IDの扱い、iNaturalistの版・科、S-Netの標本・階級・科・ライセンス照合: Pythonの18テスト。
- 実際の画面部品を使うブラウザ操作: チョウ・テントウムシ・昆虫追加分の固定候補で和名、学名、相対スコア、各出典・学名対応・利用条件リンク、種名フィールドへの反映、改名失敗／成功を確認。出典の折りたたみと標本の提供機関の表示も確認。
- TypeScript／ViteとMacアプリのビルド、アプリおよびZIP再展開後の署名検証。
- 開発用の取得スクリプトが全361件のキャッシュから同じ照会結果・対象範囲を再現することを確認。
- 昆虫追加辞書と監査記録を10,224応答のキャッシュから通信せず再生成し、両ファイルのSHA-256が一致。
- 今回の拡充分も取得済み資料から通信せず再生成し、辞書・監査記録のSHA-256が一致。S-Netの抽出・照合も取得済みCSVと79 API応答から再現。
- マニュアルの6画面を現行UIで再撮影。推測結果は説明用の固定応答と明記。

ブラウザ操作はOS側の応答を置き換えた表示・操作の検証で、写真の再推論やWindows実機検証ではない。今回のWindows実機での確認は未実施。Mac確認用ZIPはローカルに作成し、push・リリース公開は行っていない。
