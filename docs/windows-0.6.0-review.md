# Windows 0.6.0 検証結果の確認と受け入れ判断

確認日: 2026-09-22。提供された `windows-0.6.0-verification-results.md` に基づく文書レビューであり、Mac上でWindows試験を再実行したものではありません。

## 受け入れ判断

Windows 11 x64のCPU版は主要動作を確認済みです。**判定中の強制終了で専用Pythonが残る件は、利用者の指定により注意事項を記載して許容します。** この件の修正を受け入れ条件にはしません。元の報告書の「不合格」は当初の検証基準による判断であり、本書は報告された事実を変えず、この制約の扱いだけを更新します。未実施項目は未検証のままです。

[利用時の注意と残留プロセスへの対処](species-option.md#windowsで判定中にアプリを終了する場合の注意)を参照してください。今回の変更は文書のみで、アプリの終了処理は変更していません。

## 確認できた範囲

- Windows 11 Pro Build 26200、Ryzen 9 7940HS、RAM約29GB、NVIDIAなしの1台で確認。
- Nodeテスト2件合格、Rustテスト13件合格・1件想定どおり除外。フロントエンドとNSISのビルド、インストール、0.6.0の起動に成功。
- インストール版は開発サーバー・管理画面・ソース接続を要求せず単独起動。写真表示・比較・拡大・レビュー・設定保持を確認。
- CPU版の導入、有効化、無効化、再有効化、削除に成功。専用CPython 3.12とvenvを使用し、専用領域は約10.38GiB。
- 既存Pythonとランチャーの検索結果・バージョン・Python関連レジストリは不変。管理者権限やGPUドライバーの追加を要求しなかった。PATH文字列の完全一致は採取条件が違うため未確定。
- 候補選択だけでは写真を変更せず、明示的な確定時にJPEGと同名RAWを改名。判定ダイアログを閉じて別写真へ移動しても古い結果を適用しなかった。
- 通常の判定完了後は専用Pythonが終了。追加データ削除後も写真・RAW・レビュー・サムネイルが残り、標準機能が動作。

## 判定結果の読み方

これは2枚の機能確認で、一般的な正解率の測定ではありません。相対スコアは正解確率ではありません。候補に正解が含まれない場合もあるため、人が確認して反映します。日本補正は日本で撮影した写真に使ってください。今回の昆虫の結果について、補正の有無による比較試験は報告されていません。

## 許容する制約と未検証項目

判定開始約2秒後にアプリを強制終了すると、専用Pythonが2個、5秒以上残りました。手動停止後の再起動・判定は成功しています。これは通常のウィンドウ終了試験ではなく、残留プロセスが自然終了するまでの時間も不明です。

以下は今回の受け入れで合格に変更しません。

- 通常のウィンドウ操作による判定中の終了、導入中断後の復旧。
- ネットワーク完全切断下の判定、日本の生息記録だけ取得できない場合。
- 写真管理・公開ソフトや開発環境のない専用PC、両ソフトの同時起動時の相互非干渉。
- 同じ条件で採取した導入前後のPATH完全比較。
- NVIDIA GPUでの実機動作。
- 不鮮明な写真、日本以外の写真、PNG・WebPの実判定。

検証時の `npm ci` の監査ではhighが3件ありました。公開準備で開発・ビルド用のVite / PostCSS / nanoidと特定し、互換範囲内で更新しました。更新後の `npm audit` は0件です。公開版は更新したロックファイルで再ビルドするため、下記の実機検証済みインストーラーとは別のファイルです。実機の判定結果は当初の検証物に対する記録として扱います。
