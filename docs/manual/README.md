# マニュアルの更新

公開本文は `index.html`、見た目と印刷用の指定は `manual.css`、モバイル目次の初期表示は `manual.js` にあります。外部フォントや外部スクリプトを使わない静的HTMLで、ローカルでも開けます。

## 対象と管理

- 対象アプリ: v0.5.5。初版作成: 2026-09-21。
- `docs/` をGitHub Pagesで公開すると、紹介ページの `manual/` 配下になります。
- 機能追加や修正時は、該当章・操作早見表・対象バージョン・更新日を実装と照合して更新します。
- アプリを変更しない説明のみの更新では、アプリのバージョンを変更しません。
- READMEは概要とマニュアルへの入口、CHANGELOGは版ごとの変更、マニュアルは操作方法を担当します。

## 画面写真

`images/` はv0.5.5の共通フロントエンドをChromeで操作して撮影した画面です。デスクトップのネイティブファイル処理を検証した写真ではありません。本文にも撮影条件を記載しています。

公開用の観察写真を一時的なファイル入力から読み込み、個人のパスやGPSを含めず撮影しています。元の写真はマニュアルに別途コピーしていません。

| ファイル | 操作 |
| --- | --- |
| `overview.png` | 1枚目をMでチェックし、右キーで2枚目へ移動 |
| `compare.png` | チェックを解除し、2枚比較に切り替え |
| `crop.png` | 1枚表示に戻し、Shiftドラッグで範囲を選択、3:2を指定 |
| `settings.png` | 範囲選択を取消後、設定ダイアログのみ撮影 |

撮影に使用した画像は、同じ所有者の「デジタル観察のススメ」プロジェクトの `public/images/large/` にある公開用画像です。

## 更新時の確認

1. ボタン名とショートカットは `index.html` と `src/main.ts`、保存範囲は `src-tauri/src/lib.rs` と照合する。
2. ファイル移動・チェック範囲・評価の対象、RAWの扱いなどは特に確認する。
3. HTMLをデスクトップ幅とスマートフォン幅で表示し、横にはみ出す文字やリンク切れ、画像の欠落を確認する。
4. 印刷プレビューで目次を除いた本文・画像・表が収まるか確認する。
5. OS固有の動作を実機で検証していない場合、検証済みとして記載しない。

v0.5.5の注意事項として、先読みの実効上限、容量設定の対象がアプリ共通キャッシュのみであること、範囲チェックが非表示画像を含む場合があること、リロードが追加専用であること、クロップ2倍がLanczos補間であることを明記しています。実装改善後はこれらの説明も更新してください。
